## 원본에서 뽑은 것

| 구분 | 내용 |
|---|---|
| 오늘의 메시지 (덱 p2) | ① 고장을 미리 아는 것은 비용이 아니라 생존 ② 유지보수는 사후→예방→예측→처방으로 진화 ③ 한 번의 튐(노이즈)이 아니라 추세적 상승이 진짜 신호 |
| 용어 (덱 p12·p14·p19) | 이상 패턴: 평소와 크게 다른 값이나 흐름 · 노이즈: 한 번 튀고 곧 정상으로 돌아오는 일시적 값, 정비 신호가 아님 · 추세: 임계선을 향해 꾸준히 오르는 흐름, 그 시작점이 정비 신호 · 평상 범위 = 평균 ± 2표준편차 |
| 실습 단계 | 덱 AI 노코드 6단계 ① 환경 ② 데이터 ③ 전처리(평균 ± 2σ) ④ 분석1(노이즈 vs 추세, 정비 필요 시점) ⑤ 분석2 ⑥ 평가 — 실습판은 ①, ③+④만 쓴다 |
| 판정 규칙 (따라하기 II 프롬프트 3) | 처음 12점(08:00~11:40) 기준선, 기준선 상한 = 평균 + 3σ, 상한 3번 연속 초과 = 추세(첫 시각 = 추세 시작), 연속이 아니면 노이즈 |
| 현장 케이스 (덱 p8) | 한 제조사가 진동을 상시 감시하다 평소와 다른 미세한 진동 증가를 포착해 고장 직전 부품 교체 — 며칠치 생산 손실을 막음 |
| 실습과제 · 모범답안 (덱 p25·p27) | [1.0→1.1→0.9→3.5→1.0] vs [1.0→1.3→1.7→2.2→2.9] — 정답은 두 번째(추세). 감점: "한 번 높았으니 위험" |
| 공개 (따라하기 II 프롬프트 6) | 올릴 파일 목록·개인정보 점검 → gh 로그인(일회용 코드는 사용자가 직접) → 공개 저장소 + Pages(main, 루트) → 주소 표시 |

## 정답 수치 — 원본 값 / 직접 계산 값

| 항목 | 원본 (정답 메모 · 따라하기 II) | 직접 계산 (`forge/qa/source_check.py`) |
|---|---|---|
| ±2σ 이상 후보 설비A | 12:40 진동 3.5 (노이즈형) | 12:40 진동 3.5 — 같음 |
| ±2σ 이상 후보 설비B | 진동 2.2·2.9, 온도 65.1 | 15:40 진동 2.2, 16:00 진동 2.9, 16:00 온도 65.1 — 같음 |
| 추세 시작 설비B | 온도 13:00 · 진동 15:00 | 온도 13:00 · 진동 15:00 — 같음 |
| 설비A 판정 | 노이즈 | 3연속 초과 없음 → 노이즈 — 같음 |
| 조기 포착 | 160분 빠름 | 13:00 vs 평상 범위 첫 포착 15:40 → 160분 — 같음 |

표준편차는 표본 표준편차(n−1)로 계산했다.

## 가정과 확인 필요
- 실습판 STEP 4 예시 프롬프트는 "진동 선 그래프 + 추세 시작 시각"인데, 점검표 기준값 13:00은 설비B **온도**의 추세 시작이다(진동은 15:00). 그래프에 설비B 온도를 함께 넣어 두 값이 모두 보이게 한다.
- 10분 안에 끝내기 위해 단위 혼재 점검·파일럿 선정·보고서는 넣지 않는다.
