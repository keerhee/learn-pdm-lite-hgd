## 실습 MVP 계획

- 데이터: `data/Day5/Day5_설비센서_50건_가상.csv` (가상, 2026-09-15 08:00~16:00, mm/s·℃·bar)
- 정답: `assets/answers/trend_check.py` → `expected.json`
- 확인할 핵심 수치: 설비A 노이즈(12:40 진동 3.5) · 설비B 온도 추세 시작 13:00 · 진동 15:00 · 평상 범위보다 160분 빠름 — 원본 정답과 직접 계산 값이 모두 같다
- 그래프: 설비A 진동 · 설비B 진동 · 설비B 온도(오른쪽 축), 12:40·13:00·15:00 표시

## 원본과 다르게 정한 곳

- 6단계 중 ① 환경 · ③ 전처리 · ④ 분석1만 쓴다 — 10분 실습판이라서.
- 퀴즈는 B1 1문항만, B0·B2는 확인만 한다 — 사용자 요청.
- 배포와 공유를 B2 하나로 합친다 — 공유 메시지는 실습판 STEP 5에서 따로 만든다.

## 위험과 가정

- GitHub 로그인이 안 된 수강생은 B2에서 일회용 코드 입력 시간이 더 걸린다.
- 그래프 라이브러리는 CDN(Chart.js)에서 불러온다. 수업장 인터넷이 막혀 있으면 그래프가 안 보일 수 있다.
