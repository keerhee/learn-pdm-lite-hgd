## EXPLAIN

### 1. 오늘 다룰 데이터

| 용어 | 뜻 |
|---|---|
| 다변수 센서 데이터 | 진동·온도·압력처럼 여러 변수를 동시에 시간 순으로 기록한 데이터. 한 변수만으로는 놓치는 이상을 여러 변수를 함께 보면 잡아낸다. |
| 진동 (mm/s) | 베어링·회전체 마모, 정렬 불량을 본다. 갑작스러운 증가·추세적 상승이 전조. |
| 온도 (℃) | 마찰·과부하·윤활 부족을 본다. 서서히 오르는 흐름이 위험 신호. |
| 압력 (bar) | 유압·공압 계통 누출·막힘을 본다. 평상 범위 이탈 구간을 표시. |

오늘 쓰는 파일은 원본 강의 저장소의 `Day5_설비센서_50건_가상.csv`다. **실습용 가상 데이터**이고, 설비 2대 × 25시점(2026-09-15 08:00~16:00, 20분 간격)이다.

| 설비 | 이름 |
|---|---|
| 설비A | 프레스 메인모터 |
| 설비B | 차체 용접로봇 감속기 |

### 2. 왜 단위부터 보는가

| 기준 | 바로 분석 | 단위 먼저 확인 |
|---|---|---|
| 섞인 단위(℉·in/s·psi) | 튀는 값처럼 보여 이상 판단이 흔들린다 | 분석 전에 걸러진다 |
| 결과 신뢰 | 숫자가 왜 튀었는지 설명 못 한다 | "같은 단위로 비교했다"고 말할 수 있다 |

원본 덱 ② 데이터 단계: "단위(℃, mm/s, bar)와 측정 주기를 먼저 확인한다 — 단위가 섞이면 이상 판단이 흔들린다."

### 3. 현장 장면

조립 라인은 한 곳이 멈추면 뒤 공정이 줄줄이 멈춘다. 라인 정지 1분 손실이 수천만 원이라서 "고장을 미리 아는 것"이 생존의 문제가 된다(원본 덱 p6). 그 판단의 재료가 오늘 준비하는 센서 기록이다.
